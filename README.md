# Finora — Personal Expense Manager

A premium React + CSS personal expense manager inspired by the project brief.

## Features
- Premium responsive dashboard
- Income and expense tracking
- Add, edit and delete transactions
- Search and category/type filtering
- Monthly budget with progress tracking
- Category spending breakdown
- Income vs expense visual chart
- Analytics and financial summary
- CSV export
- Dark / light premium themes
- LocalStorage persistence
- Responsive mobile layout
- Premium gradients, glassmorphism and micro UI
- No backend required

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Deployment

This is a static Vite application. It can be deployed to Netlify, Vercel or GitHub Pages after running `npm run build`.

All transaction data is stored in the browser's LocalStorage.
